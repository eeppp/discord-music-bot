# Music S3YD

بوت موسيقى عربي لـ Discord مع مشغّل واحد يتحدّث باستمرار، قوائم تفاعلية مناسبة للجوال، بحث YouTube وSoundCloud، وقائمة انتظار لكل خادم.

## التشغيل

1. أنشئ تطبيق Bot في Discord Developer Portal وأضف البوت إلى خادمك.
2. فعّل Message Content Intent من صفحة Bot في Developer Portal.
3. عيّن المتغير DISCORD_TOKEN إلى رمز البوت. لا تضع الرمز في GitHub.
4. شغّل:
   - محليًا: python bot.py
   - على Railway: انشر المستودع باستخدام Dockerfile، وأضف Volume إلى `/app/database` ثم اضبط `DATABASE_PATH=/app/database/music.db` للحفاظ على إعدادات الخوادم بعد إعادة النشر.

يحتاج البوت في Discord إلى View Channels وSend Messages وEmbed Links وRead Message History وConnect وSpeak. يحتاج أمر تنظيف إلى Manage Messages على البوت، وإلى صلاحية Manage Messages للمستخدم الذي ينفذه.

## إعدادات البيئة

الإعدادات الأساسية موجودة في .env.example. انسخه إلى .env للتشغيل المحلي، أو أضف المتغيرات إلى Railway:

- DISCORD_TOKEN: رمز البوت، مطلوب.
- BOT_PREFIX: بادئة الأوامر، افتراضيًا !.
- DEFAULT_VOLUME: مستوى الصوت الافتراضي بين 0 و200.
- AUTO_PLAY: تفعيل التشغيل التلقائي، افتراضيًا true.
- DATABASE_PATH: مسار قاعدة SQLite.
- DELETE_DELAY: مدة بقاء ردود البوت المؤقتة بالثواني.
- MAX_QUEUE: الحد الأقصى للأغاني في قائمة الانتظار.
- DJ_ROLE: اسم دور DJ الافتراضي، ويمكن للإدارة تعيين دور آخر من داخل الخادم.
- EMBED_COLOR: لون واجهة البوت بصيغة hex.

لا ترفع ملف .env أو قاعدة البيانات إلى GitHub.

## الأوامر العربية

- !شغل اسم الأغنية أو الرابط: يبحث ويعرض أفضل خمس نتائج، أو يشغّل الرابط مباشرة.
- !صوت 0-200: يضبط الصوت. يمكن أيضًا استخدام قائمة الصوت في لوحة المشغّل.
- !تخطي: يتجاوز الأغنية الحالية.
- !تكرار: يبدّل تكرار الأغنية الحالية.
- !خلط: يخلط الانتظار.
- !قائمة: يعرض قائمة الانتظار.
- !وقف: إيقاف مؤقت أو استئناف.
- !كمل: استئناف التشغيل.
- !باس 0-10: يضبط تعزيز الجهير ويعيد تطبيقه على الأغنية الحالية من موضعها.
- !تأثير [normal/bass/treble/nightcore/8d]: يختار مؤثرًا أو يفتح قائمة المؤثرات.
- !تعيين-دي-جي @دور: يحدد دور DJ؛ الأمر متاح لمن لديه إدارة الخادم.
- !تلقائي: يبدّل Autoplay. ويمكن تمرير on أو off.
- !إيقاف: يوقف التشغيل ويفصل البوت.
- !تنظيف: يحذف رسائل البوت القديمة في القناة مع الحفاظ على لوحة المشغّل.
- !مساعدة: يعرض هذه القائمة.

الأوامر متاحة كذلك بصيغة Slash بعد مزامنتها عند تشغيل البوت. إضافة الأغاني وعرض الانتظار متاحان للأعضاء، أما التحكم بالتشغيل والصوت والمؤثرات فيتطلب دور DJ المحدد أو صلاحية إدارة الخادم. يستطيع مدير الخادم تعيين الدور عبر !تعيين-دي-جي @دور، أو تركه فارغًا للعودة إلى DJ_ROLE. لوحة المشغّل تُحفظ وتُستعاد أزرارها بعد إعادة تشغيل البوت. تعتمد جودة تشغيل YouTube وSoundCloud على دعم yt-dlp للمصدر وتوفّر FFmpeg في بيئة التشغيل.

تغيير Bass Boost أو المؤثر أثناء التشغيل يعيد تشغيل البث من موضع الأغنية الحالي؛ قد يحدث انقطاع صوتي قصير أثناء إعادة تطبيق الفلتر. إذا لم تكن هناك أغنية تعمل، يُستخدم الإعداد عند بدء الأغنية التالية.
